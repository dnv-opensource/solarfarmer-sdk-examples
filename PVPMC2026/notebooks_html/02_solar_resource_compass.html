3. Weather Comparison — compare_weather()¶

The /wcompare endpoint pulls irradiance and weather data from multiple satellite and ground-based datasources for the site, runs DNV's quality-checking methodology, and returns:

  • summary — which datasource was selected as the TMY and why
  • metadata — per-datasource GHI, DHI, temperature, wind, and quality flags
  • weather_monthly — monthly aggregates per datasource
  • weather_hourly — the selected 8 760-record TMY hourly dataset

This is the first step in any resource assessment workflow.

5. Soiling Profile — get_soiling()¶

Soiling reduces PV output by depositing dust and snow on module surfaces.
The /soil endpoint combines:

  • Dust model — accumulation rate (driven by dust_soil_type) counteracted by rainfall wash events
  • Snow model — based on nearby NOAA ground stations

Key parameters to explore¶

Parameter Default Options / range
dust_soil_type mild_soil light_soil, mild_soil, moderate_soil, heavy_soil, severe_soil
mounting roof_fixed roof_fixed, carport_fixed, ground_fixed, ground_1axis
array_tilt 10 ° 0–90 °
precip_wash_thresh 6.25 mm Minimum rainfall for a clean event

Try it: change dust_soil_type to "heavy_soil" or mounting to "ground_fixed" and re-run to see how the profile changes.

    plot_cols = []
    if dust_col:
        plot_cols.append(dust_col)
    if snow_col:
        plot_cols.append(snow_col)

    colors = {dust_col: "#e07b39", snow_col: "#6baed6"}

7. Albedo Profile — get_albedo()¶

Ground reflectance (albedo) affects bifacial PV yield.
The /albedo endpoint provides:

  • metadata — details of the NOAA station used for snow-cover modelling
  • monthly_profiles — monthly albedo value + number of snow-cover days

Typical bare-ground albedo is ~0.2; snow can push it above 0.6.
