Solcast API — PVPMC 2026 Workshop¶

Getting solar resource data programmatically with the Solcast Python SDK

Thursday 14 May 2026 · PVPMC Workshop, Albuquerque (NM)

This notebook demonstrates four key data-retrieval workflows using the Solcast API Python SDK:

Module Method What it returns
solcast.tmy radiation_and_weather() Typical Meteorological Year — 8 760-record hourly dataset
solcast.historic radiation_and_weather() Satellite-derived actuals from 2007 to -7 days at up to 5-minute resolution
solcast.live radiation_and_weather() Satellite-derived actuals for -7 days to -5 minutes
solcast.forecast radiation_and_weather() Irradiance and weather forecasts up to 14 days ahead

SDK documentation: https://solcast.github.io/solcast-api-python-sdk/
API documentation: https://docs.solcast.com.au/

Before you start¶

  1. Sign up for a Solcast API key.
  2. Set it as an environment variable:
    • Windows: set SOLCAST_API_KEY=your-key
    • Mac/Linux: export SOLCAST_API_KEY=your-key
  3. Run each cell in order — the cells build on each other.

3. Available Weather Parameters¶

The radiation_and_weather endpoint exposes a broad set of meteorological variables.
Pass any subset as a list (or comma-separated string) via output_parameters:

Irradiance

Parameter Units Description
ghi W/m² Global Horizontal Irradiance
ghi10 W/m² GHI — 10th percentile (cloudier than expected)
ghi90 W/m² GHI — 90th percentile (less cloudy than expected)
dhi W/m² Diffuse Horizontal Irradiance
dhi10 W/m² DHI — 10th percentile
dhi90 W/m² DHI — 90th percentile
dni W/m² Direct Normal Irradiance
dni10 W/m² DNI — 10th percentile
dni90 W/m² DNI — 90th percentile
gti W/m² Global Tilted Irradiance (tilted / tracking surface)
gti10 W/m² GTI — 10th percentile
gti90 W/m² GTI — 90th percentile
clearsky_ghi W/m² GHI under clear-sky conditions
clearsky_dhi W/m² DHI under clear-sky conditions
clearsky_dni W/m² DNI under clear-sky conditions
clearsky_gti W/m² GTI under clear-sky conditions
cloud_opacity % Cloud attenuation of incoming sunlight (0 = clear, 100 = fully opaque)
cloud_opacity10 % Cloud opacity — 10th percentile clearness
cloud_opacity90 % Cloud opacity — 90th percentile clearness

Temperature & Humidity

Parameter Units Description
air_temp °C Air temperature at 2 m
min_air_temp °C Daily minimum air temperature at 2 m
max_air_temp °C Daily maximum air temperature at 2 m
dewpoint_temp °C Dewpoint temperature at 2 m
relative_humidity % Relative humidity at 2 m

Wind

Parameter Units Description
wind_speed_10m m/s Wind speed at 10 m
wind_speed_100m m/s Wind speed at 100 m
wind_direction_10m ° Wind direction at 10 m (0 = north, 270 = from west)
wind_direction_100m ° Wind direction at 100 m
wind_gust m/s Maximum wind gust at 10 m (3-second average)

Precipitation & Snow

Parameter Units Description
precipitation_rate mm/h Average precipitation rate (not accumulated)
snowfall_rate cm/h Snowfall rate (depth of fresh snow per hour)
snow_depth cm Physical snow pack depth on the ground
snow_water_equivalent cm Snow depth liquid-water equivalent
snow_soiling_ground % DC production loss from snow on ground-mounted modules
snow_soiling_rooftop % DC production loss from snow on rooftop modules

Atmospheric & Air Quality

Parameter Units Description
surface_pressure hPa Air pressure at surface level
precipitable_water kg/m² Integrated water vapour column
albedo fraction Daytime average surface reflectivity (0–1)
pm10 μg/m³ Particulate matter ≤ 10 μm
pm2.5 μg/m³ Particulate matter ≤ 2.5 μm
cape J/kg Convective Available Potential Energy (thunderstorm indicator)

Sun Position & Classification

Parameter Units Description
azimuth ° Solar azimuth (−180 to 180; −90 = east, 0 = north, 90 = west)
zenith ° Solar zenith angle (90° at sunrise/sunset, 0° overhead)
weather_type string Simple categorisation of weather conditions

4. Typical Meteorological Year (TMY) — tmy.radiation_and_weather()¶

A TMY is a synthetic one-year hourly dataset derived from multiple years of satellite data.
It captures the typical weather pattern for the location — the standard input for annual energy yield models.

The tmy module returns 8 760 hourly records at 30-minute or 60-minute resolution.

In [4]:

5. Historic Data — historic.radiation_and_weather()¶

The historic endpoint provides satellite-derived actuals from 2007 to seven days ago at up to 5-minute resolution.
Data is immutable and quality-controlled — ideal for resource studies, model validation, and gap-filling.

Key parameters:

Parameter Example Notes
start '2024-07-01T00:00' ISO-8601 timestamp (UTC)
duration 'P7D' ISO-8601 duration — up to 31 days per call
period 'PT30M' Time step: PT5M, PT30M, or PT60M

Note: Each call counts as one API request, regardless of the time window requested.

In [6]:
%%time
from solcast import historic

historic_data = historic.radiation_and_weather(
    latitude=LATITUDE,
    longitude=LONGITUDE,

6. Live Data — live.radiation_and_weather()¶

The live endpoint provides near-real-time observations continuously updated as satellite imagery is processed.
It covers the past few days up to the present moment — useful for monitoring dashboards and nowcasting.

Additional parameters available when requesting plane-of-array irradiance:

Parameter Example Notes
tilt 23 Module tilt in degrees (0 = horizontal)
azimuth 150 Azimuth in degrees (0 = north, 180 = south)
hours 24 * 5 How many hours back from now to retrieve
period 'PT5M' Time step: PT5M or PT30M
In [8]:
%%time
from solcast import live

live_data = live.radiation_and_weather(
    latitude=LATITUDE,
    longitude=LONGITUDE,
    output_parameters='ghi,air_temp,weather_type',
    period='PT5M',    # 5-minute resolution
    hours=24 * 5,     # last 5 days
    tilt=23,          # module tilt angle for GTI calculation
    azimuth=150,      # azimuth (0 = north, 180 = south)
    api_key=API_KEY,
).to_pandas()

7. Forecast — forecast.radiation_and_weather()¶

The forecast endpoint returns irradiance and weather predictions up to 14 days ahead.
Short-range forecasts (~4 h) are satellite-nowcast based; beyond that, numerical weather models take over.

This example retrieves the two parameters most commonly used in dispatch and yield-prediction workflows:

Parameter Description
ghi Global Horizontal Irradiance (W/m²)
air_temp Air temperature (°C)
In [10]:
%%time
from solcast import forecast

FORECAST_PARAMETERS = ['ghi', 'ghi10', 'ghi90', 'air_temp']

forecast_data = forecast.radiation_and_weather(
    latitude=LATITUDE,
    longitude=LONGITUDE,
    output_parameters=FORECAST_PARAMETERS,
    period='PT30M',   # 30-minute resolution
    hours=48,         # next 48 hours
    api_key=API_KEY,
).to_pandas()

print(f"Forecast dataset: {len(forecast_data)} records")
