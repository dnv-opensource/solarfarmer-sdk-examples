Notebooks for the DNV Green Data Products API training session at PVPMC 2026.

## Environment Setup

Dependency files are provided to reproduce the Python environment:

- `pyproject.toml` — project metadata and dependencies
- `uv.lock` — locked dependency versions for reproducible installs (use with [uv](https://github.com/astral-sh/uv))
- `environment.yml` — Conda environment specification
